## Websocket API

| Endpoint | Method | Description |
|-----|-----|-----|
| [testVersionNotSupported](#test-version-not-supported) | websocket | Test version not supported |

<br>

<a name="test-version-not-supported"></a>

### Test version not supported

**Method:** websocket

**Endpoint:** testVersionNotSupported

**Request:** 

<pre>
{ empty }
</pre>

**Response:** 

<pre>
{
    "error": { "status": bool, "code": int, "message": string }
}
</pre>

<br>

<a name="invalid-connection-event"></a>

### Invalid connection event

**Event:** invalidConnection

**Description:** Event is automatically emitted when second socket connection is initiated for user session or network is reset

**Data:** 

<pre>
{
    "error": { "status": bool, "code": int, "message": string }
}
</pre>

<br>
