## Partner: Auth API

| Endpoint | Method | Description |
|-----|-----|-----|
| [/api/v0/partnerRpc/auth.registerUser](#register-user) | jsonRpc | Register user |
| [/api/v0/partnerRpc/auth.getUserByEmailAndPassword](#get-user-by-email-and-password) | jsonRpc | Get user by email and password |

<br>

<a name="register-user"></a>

### Register user

**Method:** jsonRpc

**HTTP Method:** POST

**Path:** /api/v0/partnerRpc/auth.registerUser

**Request:** 

<pre>
{
    "email": string
    "password": string
    "firstName": string
    "lastName": string
}
</pre>

**Response:** 

<pre>
{
    "data": {
        "userId": string
    }
    "error": { "status": bool, "code": int, "message": string }
}
</pre>

<br>
